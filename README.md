# Topdown GTA-like

A 2D open-world game inspired by GTA2, made with Python and Pygame.  
Based on a Clear Code YouTube tutorial, with my own modifications and improvements.

## Run

Install Pygame:

```bash
pip install pygame
```

Run the game:

```bash
python main.py
```
